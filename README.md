# 🌸 Mirai - Assistente Virtual VTuber

[![Python](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Assistente virtual com personalidade própria que roda 100% localmente!

## 🚀 Início Rápido
```bash
# 1. Clone o repositório
git clone https://github.com/HarukiMuraka/Mirai.git
cd Mirai

# 2. Instale dependências
pip install -r requirements.txt

# 3. Execute
python run.py
```

## ✨ Funcionalidades

- 🗣️ **Conversa Natural** - Bate-papo por voz e texto
- 🤖 **Assistente Inteligente** - Abre apps, pesquisa, automatiza
- 🎮 **Modo Gamer** - Interação durante jogos e streams
- 🎭 **Avatar VTuber** - Integração com VSeeFace (opcional)
- 🔌 **Extensível** - Sistema de plugins para adicionar funcionalidades
- 💾 **Privacidade** - Tudo roda localmente (Ollama)
